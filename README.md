# EPOCH — 公開パッケージ

マンガ「EPOCH — 時代の前夜」の**読者に配る版**を置く配信先。

- 公開 URL: https://manga-epoch.github.io/viewer/
- 制作の単一出典は別リポジトリ（life, private）。ここは**生成物の配信先**で、
  中身は CI（sync-viewer）が同期する。直接編集しても次の同期で消える。

## 中身

| パス | 内容 | 公開範囲 |
|---|---|---|
| `/` | 作品紹介・価格のページ | 誰でも |
| `/pub/epoch/arc1/` | Arc 1「黎明」全 3 話 | 無料 |
| `/pub/epoch/arc2/` | Arc 2「覚醒」試読版（第 1 話＋解説第 1 章） | 無料 |
| `/pub/epoch/a2-*/` | Arc 2 製品版 | アクセスコードを知る人だけ |
| `/pub/g_test_2026_05/` | G 検定の図解（巻末解説から参照） | 誰でも |
| `/unlock.html` | アクセスコードの入力 | 誰でも |

## なぜ開発用と分けているか

商用の本番物は「購入者が見るもの」で、**公開 URL に個人名を出さない・余計なものを混ぜない**
という要求がある。学習ノートの図解や制作中のレビュー用ページと同じ場所に置くとその線引きが
崩れるため、開発用は別リポジトリ（`yhdk0307-ai/viewer`）に分けている。
