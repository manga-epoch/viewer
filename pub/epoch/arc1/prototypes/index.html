Self-Attention おまけ本番に既に入った 3 要素（① attention 分布 / ② N×N ヒートマップ / ③ 温度付き次トークン）を超えて、Transformer の核心を体感する 3 プロトタイプを試作。採用するなら Arc 2 図解パックの素材か、Arc 1 おまけに統合候補。

GPT パイプライン全景 (プロトタイプ ①)

入力テキスト → トークン化 → 埋め込み → 多層 Transformer ブロック → unembed → softmax → 次トークン。GPT が文を生成するまでの 10 段階を縦フローで見せ、各ブロックをタップして詳細展開。テンソル形状とパラメータ数も明示。

QKᵀ → softmax → ×V ステップ (プロトタイプ ④)

小サイズ（N=4, dₖ=2）の具体例で attention 計算を 4 ステップに分解。Q（青）・ K（緑）・ V（紫）の色を統一し、行列乗算 → 正規化 → softmax → 重み付き和を「次へ」ボタンで段階的にトレース。色付き数値表で各ステップの中身が見える。

🎭

Multi-Head Attention 並列ヒートマップ (プロトタイプ ⑤)

同じ文「彼は本を買った。それを読んだ。」を 4 つの head が並列に処理する様子。Head ごとに「局所注意 / 主述対応 / 指示語解決 / 文末区切り」と異なる "視点" を学習する典型パターンを示す。タブ切替 + 4 マップ俯瞰モード。
