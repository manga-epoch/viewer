図解一覧 — Arc 1「黎明」

マンガで描いた 1956 年ダートマス会議 (Scene 1)、1958 年パーセプトロン (Scene 2)、1976-1993 年エキスパートシステム (Scene 3) の核心を、7 本の図解で「触れて」理解する。 チューリングテスト (1950)、マカロック-ピッツ・ニューロン (1943)、単層パーセプトロン (1957)、MYCIN の IF-THEN 推論 (1976)、Cyc 常識推論 (1984)、STRIPS プランナー (1971)、そして 2017 年 Transformer の核心 Self-Attention へとつながる橋まで ―― マンガ → 解説 → 図解 の最終段階。

チューリングテスト (Scene 1)

知能を測る最初の物差し（1950）。あなたが審査員として人間と機械を見分け、さらに ELIZA のルール表を覗いて「機械が言葉を理解するふり」の仕組みを体感する。

マカロック-ピッツ ニューロン (Scene 1)

史上初の「考える部品」（1943）。1 個のニューロンを 多数決スイッチ に見立てて、AND・OR を組み立てる。XOR が作れない壁が、後の AI の冬と多層ニューラルネットへの伏線になる。

対話論理多数決
⚡

単層パーセプトロン (Scene 2 / Tech Nugget)

Rosenblatt が Cornell の教室の黒板に描いた図 (1957)。x1, x2, w1, w2, θ のスライダーで AND・OR を作り、XOR は不可能 ―― Minsky と Papert が 1969 年に証明した「単層の限界」を自分の手で体感する。

対話1957XOR 不可能
💊

MYCIN 推論チェーン (Scene 3 / Tech Nugget #1)

1976 年スタンフォードでファイゲンバウムが書いた感染症診断 ―― IF-THEN ルールと 確信度 (CF)。症状を選ぶと 3 ルールが連鎖発火し、cf が掛け算で伝播 ―― これが古典エキスパートシステムの本質。

対話1976forward chaining
🌳

Cyc 常識推論 (Scene 3 / Tech Nugget #2)

1984 年レナトが始めた「常識を全部書き下す」プロジェクト。知識グラフに事実を追加 → INFER で transitive inference が新事実を導出。Google KG・Wikidata・SPARQL の祖先。

対話1984Knowledge Graph
🤖

STRIPS プランナー (Scene 3 おまけ)

1971 年 SRI、Shakey ロボットを動かした「状態空間探索」。ブロックワールドで初期 → 目標へ plan を自動探索。現代の LLM エージェント (ReAct, AutoGPT) の祖先。

対話1971LLM agent の祖
✨

Self-Attention （おまけ）

1943 マカロック-ピッツの「重み付き和」が、2017 年に Transformer の核心 Self-Attention へ。Arc 1 で学んだ重み × softmax だけで、ChatGPT の心臓部の輪郭が見える ―― Arc 2 への橋。
