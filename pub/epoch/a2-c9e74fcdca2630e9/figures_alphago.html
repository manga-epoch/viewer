AlphaGo と MCTS — 機械が直観を見せた日

囲碁は盤面の組み合わせが宇宙の原子より多く、総当たりは不可能。2016 年 DeepMind の AlphaGo は、 人間の直観に相当する 2 つの深層ネットワーク ―― 有望な手を絞る policy network と、局面の優劣を読む value network ―― を、 モンテカルロ木探索 (MCTS) と組み合わせた。policy が探索すべき枝を絞り、value が先を読まずに局面を評価する。 李世乭との第 2 局 Move 37 は、人間のプロが「ありえない」と評した一手で、後に勝着となった ―― 機械が「美しい新手」を生んだ瞬間。 下で MCTS の 4 フェーズを 1 反復ずつ進めよう。

モンテカルロ木探索（MCTS） — 1 反復の中身

説明
囲碁は強化学習の題材だ——正解の手は誰も教えてくれず、報酬は勝敗として 対局の最後にまとめて届く。その中で「どの手が良さそうか」を絞り込むのが木探索である。 最初は根 (今の局面) しかない。「1 反復」を押すたびに 選択 → 展開 → 評価 → 逆伝播 が走り、 まだ見ていない局面は展開で新しく木に加わり、有望な枝の訪問回数が増えていく。policy が初期確率 (枝の太さ)、value が評価を与える。
構成図
「1 反復」を押して探索を始めてください。最初は根だけで、子局面はまだ展開されていません。
補足

この図のノード上の数値 (N・Q) や評価値 v は、木探索の仕組みを見せるための模式であり、実在の AlphaGo が出した値ではない(局面の評価に使っている関数もこの図のためのダミーで、本物の value network ではない)。

式と計算
UCT: $\displaystyle a^* = \arg\max_a \Big( Q(a) + c\,P(a)\frac{\sqrt{\sum_b N(b)}}{1+N(a)} \Big)$
$Q$ = 平均価値 (value net)、$P$ = 事前確率 (policy net)、$N$ = 訪問回数。勝率の高さと未探索の有望さを両立させ、探索を導く。
補足

AlphaGo Zero (2017) は人間の棋譜を一切使わず、自己対戦の強化学習だけで AlphaGo を超えた。policy/value を 1 つのネットに統合し、純粋に「自分との対局」から囲碁・将棋・チェスを学んだ (後の AlphaZero)。

導入で触れた Move 37 も、この select→expand→eval→backup の繰り返しが選び出した一手だ——AlphaGo 自身は、人間のプロがその手を打つ確率を事前分布からおよそ 1/10,000 と見積もっていたと DeepMind は報告している。
