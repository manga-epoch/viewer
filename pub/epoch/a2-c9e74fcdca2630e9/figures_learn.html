学習率 — 一歩の大きさ

説明

誤差の坂を下る。一歩が小さすぎると進まず、大きすぎると谷を飛び越えて跳ね回る。

式と計算
$w \leftarrow w - \eta\,\partial L/\partial w$
$w$ が重み、$\eta$ が学習率、$\partial L/\partial w$ が坂の傾き（勾配）。 傾きの逆向きに、学習率の分だけ進む。

正則化 — 重みへの罰則

説明

複雑さを下げる代わりに、大きな重みを使いにくくするという手がある。 L2 は全体をなだらかに縮め、L1 は要らない重みを 0 にして消す。

式と計算
L2（Ridge）: $L = 誤差 + \lambda\sum w^2$ 　　L1（Lasso）: $L = 誤差 + \lambda\sum|w|$
誤差だけでなく、重み $w$ の大きさそのものにも罰則 $\lambda$ を足して最小化する。 二乗（L2）は全体を縮め、絶対値（L1）は 0 まで落とせる。
