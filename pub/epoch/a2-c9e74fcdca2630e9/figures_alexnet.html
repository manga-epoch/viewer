2012 年に何が揃ったのか

AlexNet の構造そのものは、1998 年の LeNet の延長線上にある。 それでも 10 ポイントの断絶が起きたのは、計算する道具と学習の仕方が同時に変わったからだ。 ここでは、その中身を動かして確かめる。

逐次処理と並列処理 — CPU と GPU の違い

説明

画像の畳み込みは、同じ計算を場所を変えて何万回も繰り返す。 順番にやるか、いっぺんにやるか——この違いが効いてくる。 下の 2 つの格子はどちらも同じ 256 個の計算で、1 マス = 1 個の計算（畳み込みなら 1 か所ぶん）。 左は 1 つずつ、右は P 個まとめて塗りつぶしていく——マスが埋まる速さの違いを見てほしい。

CUDA — 描画専用の回路を、汎用計算に開いた仕組み

説明

GPU はもともと「画面の点を塗る」ための部品だった。 研究者はそれを騙して使っていた——計算したい数値を色に化けさせて描画させ、結果を読み戻す。 2007 年、NVIDIA がその回路に直接プログラムを書ける口を開けた。それが CUDA だ。

補足

役割そのものを動かす。研究者が書くのは下の数行だけ—— 「自分の通し番号を計算し、自分の 1 個だけ処理する」関数（カーネル）と、その起動行だ。 データを何個に増やしても、どの実機で走らせても、このコードは 1 文字も変わらない。 束ねて配るのは CUDA の仕事だから。下で N と実機を変えて確かめる。

__global__ void add(float *a, float *b, float *c){
  // 自分の通し番号を計算し、
  int i = blockIdx.x*blockDim.x + threadIdx.x;
  // 自分の 1 個だけ処理する
  c[i] = a[i] + b[i];
}
// 起動——いま N=96 → ブロック 12 個 × 8 スレッド
add<<<(N + 7)/8, 8>>>(a, b, c);

補足

図は模式——実物のブロックは 128〜1024 スレッド、割り付けの順序はハードが決める。 SM（Streaming Multiprocessor）は GPU の実行ユニットで、AlexNet の GTX 580 は SM 16 基 × 32 コア = 512 コア。

ドロップアウト — 学習中にノードを一定割合で無効化する正則化

説明

訓練のたびに、中間の計算点を半分眠らせる。特定の経路に頼れなくなるので、 いくつもの経路が同じ仕事を覚える。本当に効くのかを、実際のモデルで確かめる—— 使うのはニューラルネットの図解と同じ形の多層ネット （入力 2 → 中間 8 → 中間 8 → 出力 1）。AlexNet が dropout を入れたのも 全結合の 2 層で、落とす場所も同じにしてある。 わざと間違えたラベルを 8 点混ぜた 36 点を学習させ、なし／あり × 初期値 3 通り = 6 回の平均で比べる。

▶ を押すと、まずスロー再生（1 コマ = 訓練 1 点）で「どのノードが眠るか」を 上下の構成図で見比べ、そのあと なし／あり × 初期値 3 通りの測定に入る。

式と計算
$m \sim \mathrm{Bernoulli}(1-p)$
各ノードに独立なマスク $m$ を掛ける（$m=0$ になる確率が、落とす割合 $p$）。 AlexNet は全結合の 2 層に $p=0.5$ を使い、推論時はマスク無しで出力を $\times(1-p)$ した。 この実演も同じく中間 2 層に入れ、同値な「訓練時に $\times\frac{1}{1-p}$」方式を使う（数値は事前に検証済み）。
