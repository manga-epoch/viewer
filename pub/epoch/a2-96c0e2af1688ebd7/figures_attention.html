Self-Attention のしくみを、本物の数値で見る

2017 年の Transformer は、再帰をやめてSelf-Attention だけで文を処理する。 各語が自分のクエリと全語のキーを照らし合わせ、 「どの語をどれだけ参照するか」の重みを決める。 ここで見る数値は説明用の作りものではなく、実際に GPT-2 が計算した値だ。

この図解が扱うのは、Transformer ブロックの中にあるMasked Multi-Head Self-Attentionという 1 つの部品の中身だけだ。文が入って次の 1 語が出るまでの全体のフロー（トークン化 → 埋め込み → ［Self-Attention → MLP］× 12 → 出力）はTransformerにある。 ここではその中の Self-Attention の 1 段を、Q・K・V が生まれるところから出力になるところまで、順に追う。

クエリ・キー・バリュー（Q・K・V） — 検索にたとえた 3 つの役割

説明

注意の重みは、いきなり降ってくるわけではない。各トークンの埋め込み （768 次元の数の並び）に、学習した 3 つの重み行列をそれぞれ掛けて、 クエリ (Query)・キー (Key)・バリュー (Value) の 3 本を作るところから始まる。 同じ 1 つの埋め込みが、掛ける行列を変えるだけで 3 方向へ枝分かれする——下の図はそれを表す。 ボタンで役割を切り替えて読んでほしい。

式と計算
$$Q = XW^Q \qquad K = XW^K \qquad V = XW^V$$
$X$ はトークンの埋め込み（768 次元）、 $W^Q,\,W^K,\,W^V$ は学習で決まる重み行列。同じ $X$ から、掛ける行列を変えるだけで 性質の異なる 3 本のベクトルが出てくる。
構成図
Query（クエリ） Key（キー） Value（バリュー）
補足

検索エンジンにたとえるとつかみやすい。Query は検索窓に打ち込む言葉—— 「この語について、何を知りたいか」。Key は検索結果に並ぶ各ページの見出し—— 「自分は何者か」と各語が掲げる看板。Value はページの中身——照合が済んだあとに 実際に持ち帰る情報。つまり Query と Key を照らし合わせてどれが関係あるかを決め、 選んだ分だけ Value を持ってくる。次の節「①重みができるまで」の内積・softmax は、 まさにこの「照らし合わせ」の計算にあたる。

12 分割（マルチヘッド）

補足

768 次元をまるごと 1 回で使うのではなく、12 に割って 1 本あたり 64 次元ずつ扱う—— 768 = 12 × 64 の意味はこれだ。1 つの見方だけに絞らず、12 通りの見方を同時に走らせる （Multi-Head）。後の節「③12 のヘッド」では、ヘッドごとに実際に見ている場所が違うことを確かめる。

構成図

注意の重みの計算 — 4 つの段

説明

「注意の重み」は一度に出てくるわけではない。内積 → スケール → マスク → softmax の 4 段を通る。段を送って、行列がどう変わるか見てほしい。

式と計算
$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
4 段はこの式に対応する：①内積 = $QK^\top$（クエリとキーの掛け合わせ） ②スケール = $\sqrt{d_k}$ で割る　③マスク = 未来の位置を $-\infty$ にしてから ④softmax へ渡す。そうしてできた重みで、最後に $V$ を混ぜ合わせる。
構成図
補足

行がクエリ（見る側）、列がキー（見られる側）。 たとえば 4 行目 2 列目は「"powers" が " visualization" をどれだけ参照するか」。

マスク処理 — 未来の語を隠す仕組み

説明

GPT のような生成モデルは、文を左から 1 語ずつ書く。 だから「3 語目を決めるとき、4 語目以降を見てしまう」ことがあってはならない。 自分より後ろを $-\infty$ にしてから softmax を通す——それだけで、 その語の重みは 0 になる。マスクを外すと何が起きるか比べてほしい。

構成図

マルチヘッド — 12 組が別々の場所を見る

説明

Self-Attention は 1 組ではない。GPT-2 small は同じ計算を 12 組並べ、 それぞれ別の重み行列で Q・K・V を作る。結果、ヘッドごとに見ている関係が違う。 番号を切り替えて、いちばん濃い升がどこへ動くか見てほしい。

出力の合成 — V の加重和と、12 ヘッドの連結

説明

①〜③で作った重みは、それ自体が目的地ではない。その重みで各語の Value を混ぜ合わせたものが、 その語の新しい表現になる。重みが 1 語にほぼ集中していれば、ほとんどその語の Value がそのまま出てくるし、 重みが分散していれば、複数語の Value が混ざって出てくる。

式と計算
$$z_i = \sum_j \alpha_{ij}\,V_j$$
$\alpha_{ij}$ は①〜③で作った、行 $i$ の softmax 後の重み （合計 1）。$V_j$ は語 $j$ の Value。重みで Value を足し合わせたものが、語 $i$ の新しい表現 $z_i$ になる。
説明

下の図は「③12 のヘッド」で見たのと同じ例——第 5 ヘッドで "powers" が " em"（empowers の前半）へ 0.94 の重みを置く行——が、実際にどんな重みで各語の Value を 混ぜ合わせるかを示す。帯の幅（重み）は実測値だが、V の中身は模式——実際の 64 次元のベクトルではなく、「その語の Value」を表す帯として描いているだけで、 GPT-2 の V の実数値はこの図解のデータに含まれていない。

構成図

連結と線形変換

補足

ここまでは 1 ヘッド分の話。実際には 12 のヘッドがそれぞれ 64 次元の $z_i$ を独立に作り、 それを横に並べて 768 次元へ戻し、最後にもう 1 回学習した行列 $W^O$ を掛けて整える。

式と計算
$$\mathrm{MultiHead}(X) = \mathrm{Concat}(z^{(1)},\dots,z^{(12)})\,W^O$$
64 次元 × 12 本を横に並べる（$\mathrm{Concat}$）だけで 768 次元に戻る——だから次の MLP や、次の Transformer ブロックへ、そのままの形で渡せる。

数値は GPT-2 small（12 層 × 12 ヘッド）の第 1 ブロックの実測値。Transformer Explainer（Polo Club of Data Science, Georgia Tech / MIT License）が公開している事前計算データから、1 ブロック分だけを取り出して使っている。
